# 超临界水–干酪根裂解产物流动数值实验

## 1. 目标与可回答的问题

本实验只使用当前等温、全组分 O/G/W、统一 PR–Flash、Darcy 流和井模型；不在
算例中复制 EOS 或另写相平衡。目标是用最小扩展回答：

1. 超临界水与裂解产物达到局部相平衡后，各活动相的黏度如何随驱替演化；
2. 产井 H2O 与裂解产物组分质量分数如何随 PVI 变化；
3. 将裂解产物从一个重质拟组分细分为轻/中/重三组分后，突破顺序、相态和
   产出组成是否发生系统变化。

本轮不包含反应动力学、温度方程、焦炭沉积、弥散/扩散和组分吸附。因此它是
“裂解已经完成后的产物流动”实验，而不是干酪根原位裂解过程模拟。

## 2. 两级算例

| 阶段 | 算例 | 组分 | 用途 |
|---|---|---|---|
| A | `scw_kerogen_squalane_1d` | H2O + squalane | 最小二元耦合，先验证相平衡–黏度–井产出链路 |
| B | `scw_kerogen_lmh_1d` | H2O + nC4 + nC10 + squalane | 观察轻/中/重分馏与产井组成变化 |

两个阶段固定相同的 60×1×1 网格、1.2 m 长度、孔隙度 0.35、渗透率
1500 mD、653.2 K、27.74 MPa、纯 H2O 注入、0.25 PV/day 和 1 PVI 总注入量。
这样 A/B 差异只来自裂解产物组分划分，而不被流量或几何混杂。

基线初态采用有限水富集相，而非完全干启动。A 的 H2O/重质摩尔分数为
0.75/0.25（质量分数约 0.113/0.887，初始 `Sw≈0.017`）；B 的
H2O/轻/中/重摩尔分数为 0.75/0.0260417/0.0651042/0.1588542（质量分数约
0.1477/0.0166/0.1013/0.7344）。这样重质产物仍占质量主导，同时基线从第一步
就能观测油富集相和水富集相黏度，并避开“零水相首次出现”对首轮实验的数值
干扰。低含水干启动应作为后续相出现鲁棒性工况单独报告。

## 3. 观测量

### 3.1 相平衡下的黏度

`reservoir_diagnostics.csv` 每个输出时刻给出 O/G/W 三个相角色的饱和度、密度
和黏度最小/体积加权平均/最大值。主比较量为：

- `mu_o_avg`、`mu_g_avg`、`mu_w_avg`；
- `s_o_avg`、`s_g_avg`、`s_w_avg`；
- O/W、G/W 或 O/G/W 单元计数，用于判断黏度变化是否伴随相出现/消失。

严格 SCW 条件下，富烃致密流体可能被热力学相角色映射到 gas slot，不能只按
列名把 `mu_o` 解释为所有“油”。后处理同时保留 O/G/W，并给出按 O+G 相体积
加权的富烃相黏度摘要；正式解释仍应结合相组成和 `phase_presence_mask`。

黏度目前由生产 LBC 组分关联式计算。squalane 的 `Vc` 是 PR 推导占位值，故
绝对重油黏度只可用于筛选和相对趋势；相平衡的 `Tc/Pc/omega/kij` 与既有严格
SCW 二元工具保持一致。定量研究前应以实验黏度拟合 `Vc` 或显式黏度乘子，并
把拟合与留出验证分开。

### 3.2 产井组分

程序新增了通用的逐井守恒组分质量率输出：`well_history.csv` 中
`m_component_<name>` 采用模拟器符号（注入为正、采出为负），并直接复用残差
中的穿孔源汇核，不从井旁单元组成近似。后处理输出：

- 各组分正的采出质量率；
- 包含 H2O 的总产出质量分数；
- 去除 H2O 后的轻/中/重烃质量分数；
- 最终时刻摘要与水突破后的分馏曲线。

## 4. 推荐实验矩阵

先做下列最小矩阵；每次只改变一个因素：

| 组别 | 变量 | 水平 | 判据 |
|---|---|---|---|
| 基线 | 组分划分 | 单重质；轻/中/重 | 相态、黏度、产出分馏差异 |
| 压力 | 初始压力 | 27.05、27.74、29.47 MPa | 对应现有严格 SCW 三个实验压力 |
| 流速 | 注入强度 | 0.10、0.25、0.50 PV/day | 分离热力学变化与压降/流动性影响 |
| 初始产物 | 轻/中/重摩尔比 | 低轻质、基线、高轻质 | 轻组分提前突破与重质滞留 |
| 物性不确定性 | H2O–重质 `kij`、重质黏度参数 | 基线±合理范围 | 给出相平衡与黏度预测带 |

压力矩阵必须分别重新初始化 P-T-z flash；不可只在后处理中缩放。速率矩阵保持
总 PVI 相同，比较应以 PVI 为横坐标，同时报告真实时间和压差。

## 5. 数值验收

每个工况至少满足：

- 初始 P-T-z flash 收敛，组分重构误差不大于 `1e-9`；
- 每个接受时间步的组分质量平衡相对误差不大于 `1e-7`；
- 所有活动相黏度为有限正数；
- 注入井 H2O 组分率为正且其他组分为零；
- 产井各组分质量率之和与总相质量率在数值容差内一致；
- 网格加密（60→120 单元）后关键突破 PVI 和最终重质质量分数变化可接受。

若相角色在 O/G 间切换，应以组分富集和守恒质量率解释，不得把 slot 切换直接
当作物理汽化或凝结结论。

本实验按井率与单元质量通量的量级启用 Natural 方程尺度：质量残差特征量
`1e-5 kg/s`，井体积率下限取基准井率 `1.215278e-8 m3/s`。这只改变数值坐标，
不改变方程零点；其作用是防止小型岩心算例的守恒方程被 O(1) 闭合方程淹没。

## 6. 已验证的基线结果

两组默认 40×0.1 day（1 PVI）计算均完成到 4 day。A 的全程最大组分质量平衡
相对误差为 `6.32e-8`，油富集/水富集相体积加权平均黏度分别约
`9.36e-4/6.62e-5 Pa·s`，产井 H2O 质量分数约 0.853。B 的全程最大误差为
`3.75e-8`，最终平均黏度约 `3.87e-4/6.58e-5 Pa·s`，产井 H2O 质量分数约
0.860；产出烃中轻/中/重质量分数由首个已求解输出的
0.0194/0.1189/0.8618 变为 1 PVI 时的 0.0409/0.1198/0.8393，显示轻组分优先
产出。以上绝对黏度仍受未标定临界体积/黏度参数限制，应作机制筛选而非定量
预测。

## 7. 执行与后处理

```bash
make case CASE=scw_kerogen_squalane_1d -j
make case CASE=scw_kerogen_lmh_1d -j

make run CASE=scw_kerogen_squalane_1d NP=1 \
  RESULT_DIR=results/base
make run CASE=scw_kerogen_lmh_1d NP=1 \
  RESULT_DIR=results/base

python case/scw_kerogen_common/analyze_results.py \
  case/scw_kerogen_squalane_1d/results/base
python case/scw_kerogen_common/analyze_results.py \
  case/scw_kerogen_lmh_1d/results/base
```

后处理不重新计算热力学，仅整理模拟器已输出的守恒率、相黏度和相饱和度。
CSV 与图同时保留真实时间和 PVI；非基准速率工况应通过
`--pore-volumes-per-day <rate>` 传入实际的恒定注入强度。

## 8. 下一步物理扩展顺序

建议按下列顺序增加复杂度：先用实验 PVT/黏度标定三拟组分；再加入分子扩散与
机械弥散；随后增加干酪根裂解源项和焦炭/固相质量守恒；最后才加入能量方程与
非等温反应。这样每一步都能用本实验的守恒与产出曲线作为回归基线。
