## 6. SW 失败诊断

四组分 SW 使用基本线搜索时，在约 0.000694 d 附近反复出现 `DIVERGED_LINE_SEARCH`，自适应时间步由 10⁻² d 逐级缩小到 10⁻⁷ d 以下后终止。[R6]

将线搜索改为回溯法并允许更小步长后，首个 0.01 d 输出区间仍出现 `DIVERGED_LOCAL_MIN`，没有形成可用于完整运行的改进。[R7] 因此当前故障更符合多组分 SW 闪蒸/相态切换非光滑或初始态不一致，而不是单纯时间步过大。

建议下一轮在不改变井网的前提下，依次检查：

1. 对三种 EOS 分别执行无流动初始闪蒸，确认相数、相组成和相体积与给定总体组成一致；
2. 对 SW 的 H2O–nC4、H2O–nC10 先做二元组成连续扫描，定位 K 值、稳定性判据或相标签发生跳变的位置；
3. 用组成或 BIP 同伦从 PR 平滑过渡到 SW，而不是在首个流动步直接切换；
4. 初始状态使用 EOS 自洽的相饱和度与相组成，避免同一总体组成在不同 EOS 下产生完全不同的初始可动相；
5. 完成 PVT/BIP 与黏度标定后，再比较见水时间、产出组分和黏度差异带。
