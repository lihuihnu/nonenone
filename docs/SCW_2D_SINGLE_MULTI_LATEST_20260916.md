# 二维单重油组分与多组分超临界水驱数值实验

> 历史运行说明：本文结果使用已被替换的初态与 BIP，只用于追溯。
> 当前物理基线见
> [SCW_KEROGEN_PHYSICAL_BASELINE_20260916.md](SCW_KEROGEN_PHYSICAL_BASELINE_20260916.md)。

> 版本：2026-09-16 最新已完成运行。本文中的“单组分”是指烃相仅用 squalane 一个重油代表组分；计入 H2O 后，热力学体系仍为二元体系。多组分体系为 H2O–nC4–nC10–squalane 四组分。本文只把已经完成并留有原始 CSV 的运行称为“结果”，不把尚未重跑的参数修改当成新结果。

## 1. 结论摘要

1. 二维 `60×20×1`、1200 活动网格模型已完成 5 个 1 PVI 算例：单重油组分 PR/SW/CPA，以及多组分 PR/CPA。多组分 SW 在注入初期相态切换区失败，未生成 1 PVI 结果。
2. 最新已完成运行采用 653.2 K、27.74 MPa、0.25 PV/d、4 d = 1 PVI；外边界封闭，左端中央网格注纯 H2O，右端中央网格等地层体积采出。
3. 单重油组分 1 PVI squalane 采收率为 PR 51.61%、SW 52.49%、CPA 36.76%。SW 初始闪蒸为全水相，因此其早期响应和跨 EOS 比较无物理可比性。
4. 多组分 1 PVI 总烃采收率为 PR 64.45%、CPA 43.86%。PR 的 nC4/nC10/squalane 分组采收率分别为 71.91%、64.50%、64.27%；CPA 分别为 71.64%、47.21%、42.77%。
5. 五个完成算例的全程最大组分相对质量守恒误差为 `2.83×10^-9`–`2.74×10^-6`。这满足当前机制筛选目的，但尚未完成网格/时间步独立加密，因此不能标记为“网格收敛”或“已验证预测”。
6. 当前最主要的不确定性不是线性求解器，而是初始相态不一致、H2O–烃 BIP、squalane 高温高压黏度及未包含的能量/反应过程。

## 2. 物理模型与适用范围

### 2.1 控制方程与离散

- 等温、全组分 O/G/W 局部热力学平衡；
- 各组分质量守恒 + Darcy 相流；
- 结构网格、TPFA 面通量、全隐式非线性求解；
- PR、Søreide–Whitson（SW）或 PR-CPA 三种热力学描述；
- 二次型相对渗透率：`kr_o=So^2`、`kr_g=Sg^2`、`kr_w=Sw^2`；
- 未配置毛管压、分子扩散、机械弥散、吸附和 Land 捕集；
- 不含能量方程、裂解反应、生焦和孔渗变化。

因此，本实验描述的是“裂解产物已经形成后的等温组分驱替”，不是完整的超临界水热采/改质反应模拟。

## 4. 数值实验设置

| 项目 | 已完成运行设置 |
|---|---|
| MPI | 1 rank |
| 线性求解 | 直接 LU |
| 非线性求解 | PETSc SNES，全隐式 |
| SNES 绝对阈值 | `1×10^-5` |
| 输出区间 | 400 个，每个 0.01 d |
| 自适应内部步 | 开启；困难算例允许切步 |
| 最小允许步 | 配置值 `1×10^-7 d` |
| 场快照 | 每 50 个输出步，即 0、0.125、0.25、…、1 PVI |
| 质量守恒输出 | 每步、逐组分 |
| 单算例磁盘量 | 完成算例约 7.0–10.7 MiB |
| 最长实测墙钟 | 多组分 CPA 3626 s（约 60.4 min） |

验收门：初始闪蒸收敛且重构误差不大于 `1×10^-9`；活动相黏度为有限正数；井组分率与相质量率闭合；每步组分相对质量守恒误差目标不大于 `1×10^-7`。本批二元结果的全程峰值达到 `10^-6` 量级，因此应标记为“筛选可用、严格阈值未全部通过”。

黏度单位为 mPa·s。

## 8. 与近期实验研究的关系

近期实验支持把 653–673 K、25–30 MPa 作为超临界水重油研究的重要温压区间。Miao 等（2024）在 400 °C、25 MPa 岩心驱替中报告 96.27% 采收率和 61.6% 降黏率；Huang 等（2025）在反应实验中报告平均 99.4% 降黏，并把 380–420 °C 识别为较优温区。Zhang 等（2022）的实验–数值研究使用 4 相 5 组分反应模型，包含重油、轻油、气体和焦炭。

这些结果不能直接用来校验本文数值采收率，因为本文是等温、无反应、均质、定体积率且只计算 1 PVI 的局部相平衡驱替。它们的作用是界定下一阶段必须补充的能量、裂解和生焦机制，而不是给当前结果做表面上的数值吻合。

## 9. 可信度判定与下一步

当前可接受的结论：

- 代码能在二维网格上闭合组分守恒，并产生清晰的水前缘、产井见水和轻重组分分馏；
- PR 与 CPA 的完整运行可作为后续参数和物理扩展的数值基线；
- 多组分 SW 失败位置已被缩小到初始相态/相切换问题。

当前不可接受的结论：

- 不能声称 EOS 已由目标温压实验完成标定；
- 不能把 CPA/PR 黏度倍数当作真实流体黏度差；
- 不能把 SW 或 CPA 的早期见水当作可信模型差异；
- 不能声称已网格收敛、已验证、可直接外推到油藏尺度。

推荐按以下顺序推进：

1. 冻结一个可追溯参数版本，并为每次运行写入源码提交号、BIP 表和可执行文件校验和；
2. 用 EOS 自洽方法按统一目标初始 `Sw` 反求总体组成，消除初态差异；
3. 分别对 H2O–nC4、H2O–nC10、H2O–squalane 做二元相边界与 tie-line 回归；
4. 用 60×20、120×40、240×80 网格和 0.01/0.005/0.0025 d 输出步独立检查空间/时间敏感性；
5. 在物性冻结后加入弥散，再依次加入能量、裂解、生焦与孔渗变化。
