# 超临界水-CO2-n-C16一维砂管可复现数值算例报告

## 核心结论

- 六组正式算例均完成至4 PVI，最大组分相对质量闭合误差为7.019e-10。
- 当前等温代理模型给出的4 PVI采收率为87.2079%至87.2325%。
- 等储层体积流量下的CO2组分效应仅为0.001147和0.001201个百分点。
- 压力由23升至24 MPa时，纯SCW与SCW+CO2的数值变化分别为-0.0234和-0.0233个百分点。
- R10/R12在4 PVI内均未达到1% CO2突破阈值，最大出口/入口CO2组分质量率比为5.975e-06。
- 原论文物理实验中CO2带来约7.8个百分点提升，而当前模型仅给出约0.0012个百分点；因此该模型适合作为流动与守恒基线，不足以解释物理实验中的热-组成协同增产。
