# H2O–CO2–BSB 五点驱替对照（复用 nC10 二维网格）

本算例回答一个单因素问题：在总注入地层体积、网格、岩石、初态、井控、温压和热力学模型都不变时，入口 CO2/SCW 配比如何改变 0.10 PVI 时的累计产油量与采收率。

用户文字写了“四组”，但明确列出了纯 CO2、75/25、50/50、25/75、纯 SCW 五个组成。本设计保留全部五个明确组成，不擅自删除端点或中间点。

## 1. 代表组分

从 Heringer 2025 的 H2O–CO2–BSB 八组分表中保留 H2O、CO2，并把原油归并为四个具有清楚馏分意义的代表组分：

| 计算组分 | 来源组分 | 用途 |
|---|---|---|
| L | C1 + C2-3 + C4-6 | 轻端挥发与 CO2 富集 |
| M | C7-15 | 中间馏分产出 |
| H | C16-27 | 重质采收 |
| XH | C28+ | 最难动用的超重端 |

L 的临界性质、偏心因子和摩尔质量按原始摩尔分数加权；M、H、XH 使用原表值。机器可读参数与来源见 `component_lumping.csv`。主实验固定使用 PR：BSB 组分表和二元交互系数本来就是 PR 数据源，因而不会把“注入配比效应”和“EOS 切换效应”混在一起。SW 可留作后续模型敏感性分析，但不进入本次五组主对照。

## 2. 直接复用的 nC10 基准

`case_config.hpp` 直接把 `BenchmarkCommon::Grid` 和 `BenchmarkCommon::Rock` 作为别名使用，不复制第二套网格数字。下列控制量与 H2O–CO2–nC10 SCW 算例一致：

| 项目 | 固定值 |
|---|---:|
| 网格与尺寸 | 60 × 20 × 1；300 m × 100 m × 5 m |
| 单元尺寸 | 5 m × 5 m × 5 m |
| 孔隙度 | 0.20 |
| 各向同性渗透率 | 100 mD |
| 孔隙体积 | 30000 m3 |
| 温度 | 653.15 K |
| 初始压力 | 28.0 MPa |
| 生产井 BHP | 27.5 MPa |
| 注入井压力上限 | 30.0 MPa |
| 注入井 | (0, 9, 0) |
| 生产井 | (59, 9, 0) |
| 总地层体积注入率 | 9.5064263442e-5 m3/s = 0.10 PV/year |
| 终点 | 0.10 PVI = 365.25 d |
| 输出间隔 | 0.002 PVI，共 50 个区间 |

外边界封闭无流，五组均使用同一 Corey 型相对渗透率。H2O 密度采用锁定的 IAPWS+Garcia 闭合，水相黏度采用 McBride–Wright 相关式。

初始总体组成沿用 nC10 基准的 20/80 H2O/烃比例，只把 80% nC10 替换为保持 BSB 内部比例的 L/M/H/XH；另加 `1e-8` CO2 数值种子并从烃比例中等量扣除。该比例是总体摩尔组成，不宣称等于 20% 水饱和度。正式解释前必须确认初始闪蒸含油相且所有五组完成同一 0.10 PVI 终点。

## 3. 五组主实验

配比定义为入口 H2O+CO2 的摩尔分数；SCW 表示在 653.15 K、28 MPa 注入的 H2O 组分。总地层体积注入率固定，因此所有处理比较相同的 PVI，而不是比较不同吞吐量。

| 组别 | CO2 | SCW | 角色 |
|---|---:|---:|---|
| CO2_100_SCW_000 | 100% | 0% | 纯 CO2 端点 |
| CO2_075_SCW_025 | 75% | 25% | CO2 富集混合驱 |
| CO2_050_SCW_050 | 50% | 50% | 等比例混合驱 |
| CO2_025_SCW_075 | 25% | 75% | SCW 富集混合驱 |
| CO2_000_SCW_100 | 0% | 100% | 纯 SCW 端点 |

正式运行次序由固定种子 `20260915` 生成并写入 `experiment_manifest.csv`，避免物理实验扩展时把配比和运行日期/装置漂移混杂。数值模型是确定性的，同一输入重复计算不作为独立统计重复。

## 4. 预先固定的比较指标

主要终点为 0.10 PVI 的总烃质量采收率：

`R_HC = cumulative_produced_mass(L+M+H+XH) / initial_mass(L+M+H+XH)`。

同时输出：

- 累计油相地层体积产量（对生产井 `q_oil_reservoir` 随时间积分）；
- 最终油相地层流量；
- 重质采收率 `R_heavy`，即 H+XH 的累计产出质量除以初始质量；
- H2O 与 CO2 突破 PVI；
- 最终平均油/气/水饱和度；
- 注入井最大 BHP 及是否触及 30 MPa 上限；
- 最大组分相对质量闭合误差。

效应报告以纯 CO2 为基准，分别给出四个含 SCW 处理的绝对差和相对差；并检查五点曲线是否单调以及 50/50 是否偏离两个端点的线性插值。突破定义为某输出区间的出口组分质量率首次达到同区间入口质量率的 1%。

## 5. 数值合格门槛

以下门槛未全部通过时，只报告“数值结果未获准作物理解读”：

1. 初始 P–T–z 闪蒸收敛、总体组成闭合且含油相；
2. 五组全部达到 0.10 PVI；
3. 最大组分相对质量闭合误差不超过 `1e-6`；
4. 注入井 BHP 不超过 30 MPa，若发生井控切换必须单列；
5. 汇总指标不得含 NaN/Inf。

现有 H2O–CO2–nC10 SCW 三组分案例曾因高温相态/水相适用域而被标记为阻塞；本算例没有把那套 nC10 热力学状态冒充成有效结果。这里仅复用其网格、岩石、井和控制量，并用 BSB 的 PR 组分体系重新进行初态及流动预检。

## 6. 运行和汇总

从项目根目录执行：

```bash
python3 case/h2o_co2_bsb_lumped_3d_lab/scripts/validate_design.py
make -C case h2o_co2_bsb_lumped_3d_lab -j2
case/h2o_co2_bsb_lumped_3d_lab/scripts/run_matrix.sh
```

`run_matrix.sh` 按固定顺序运行五组，并调用 `scripts/analyze_results.py`。汇总目录将产生：

- `comparison_summary.csv`：五组最终指标；
- `production_history.csv`：各组油相产量曲线；
- `RESULTS_COMPARISON.md`：可直接阅读的中文比较表；
- `final_oil_comparison.svg`：最终累计产油量与采收率对比图。

所有固定设计参数同时保存在 `RUN_PLAN.json`。目前五组均完成了 0.0001 PVI 启动预检，但 25% CO2/75% SCW 在继续推进时逼近相出现边界并达到最小时间步，尚未完成 0.10 PVI 正式矩阵。启动产量仅用于数值一致性检查，不得当作最终配比优劣。具体结果和阻塞证据见 `VALIDATION_REPORT.md`。

## 7. 物理实验扩展

若把该设计迁移到真实岩心/砂箱，每个处理至少使用 3 个独立重新装填样品；按填装批次和实验日分区组，在区组内随机五个处理顺序。一次运行中的多个采样时刻不是独立重复。实验前应实测孔隙体积、渗透率、入口密度、温度均匀性和热损失，并将这些量作为新版本输入，而不是在看到产量结果后再调参。
