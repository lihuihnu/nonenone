# 物性标定数据边界

本目录只保存已逐表核对、且进入当前目标温压窗的数据摘录；不把文献图形插值或模型输出伪装成实验值。

`squalane_target_window.csv` 来自 Stevenson 等（1994），DOI `10.1016/0378-3812(94)87016-0` 的表 3 和表 5。目标窗定义为 637.2–653.2 K、26.5–29.5 MPa。窗内有四条非临界液–液共存 tie-line：637.2 K 一条、653.2 K 三条。642.2 K 的表 4 没有落在该压力窗内的非临界 tie-line，因此不能声称三温度均有同压力范围标定数据。

相组成列均为水摩尔分数。原文对高压流体–液体和液–液区报告的精度为：水富相优于 ±0.0005、squalane 富相 ±0.002；原文没有给出覆盖因子和置信水平，故 CSV 中的数值只作确定性验收带，不当作 1σ 标准差。

当前经典 PR 运行值为 `kij(653.2 K)=0.0532336595`，温度形式为
`kij(T)=kref+1005.04545(1/T-1/653.2)`。它是当前生产 flash 对上述
tie-line 组成目标的直接回归结果；在 27.74 MPa 可重现 squalane 富相端点，
但水富相端点仍超出实验容差，且端点逸度残差显示明显结构失配。因此该参数
只能称为“组成拟合基线”，不能称为同时满足两端点和化学势闭合的最终参数。

H2O–nC4 当前使用 Søreide–Whitson 非水相公开先验 `kij=0.5091`，尚未
完成目标温窗原始数据回归。H2O–nC10 使用 Teratani 表 6 的
573.2/593.2/613.2 K 三点 `0.3157/0.3167/0.2836` 回归得到
`kij(T)=-0.1646700201+278.5946242/T`；653.2 K 的 `0.2618373654` 是
明确的温度外推，不是测量值。逐行证据状态保存在
`water_hydrocarbon_bip_evidence.csv`。

`flow_screening_design.csv` 是确定性模拟用的 `2^(5-1)` Resolution-V 筛选设计，生成元为 `E=ABCD`，固定随机种子 `20260916`。F01–F16 每个条件应分别用 PR/SW/CPA 运行，C01 用于检查中心曲率；它不是随机重复，也不应用来虚构实验误差。当前程序已可直接切换 EOS；温压、注入速率、目标初始水饱和度及轻组分比例的批处理入口仍属下一步自动化，因此不得把该 CSV 记为已完成的 51 个流动运行。
