# 五组分独立参数包流动算例运行记录

## 1. 运行范围

本记录对应 `five_component_eos_tuned_compare` 的本地 WSL/PETSc 运行，日期为
2026-08-25。三种 EOS 共用同一 `20 x 20 x 5` 网格、岩石、井、初始
`P-T-z`、相对渗透率和时间表，仅热力学参数包不同。

- 组分：H2O / CO2 / CH4 / C2H6 / nC4H10；
- 初始状态：60 bar、305 K、`z=[0.30,0.10,0.15,0.15,0.30]`；
- 注入井：纯 CO2，100000 reference m3/day；
- 生产井：52 bar BHP；
- 完整时间：20 个 0.25 day 输出间隔，共 5 day；
- 完整运行：2 MPI ranks；短预检：1 MPI rank、1 个 0.05 day 时间步。

## 2. 使用的独立参数包

| EOS | 参数包 |
|---|---|
| PR | PR78 alpha、CoolProp 纯组分数据、SPE3 reservoir BIP |
| SW | 原 Søreide-Whitson PR 分支、1 mol/kg NaCl、烃类水相相关式、Chabab-2019 CO2 水相 BIP |
| CPA | 公开 SRK-CPA 纯组分、4C water、B2 单受体位点 CO2、实验 H2O-CO2 交叉缔合能/体积、逐对 BIP |

CPA 的 H2O-CO2 交叉缔合能为 142.0 bar L/mol（14200 J/mol），交叉缔合
体积为 0.0162。所有参数均在计算前确定；没有使用本算例结果反向拟合。

“优选参数”表示为每个 EOS 选择公开、与其目标物理一致的独立参数包，不表示该
组参数在所有温压和组成范围内都是全局最优。

## 6. CPA 位点求解优化复核

2026-08-25 对生产代码中的 CPA 缔合位点热点进行了等价约化。对于当前 B2
拓扑，只有 H2O 含供体位点，H2O 与 CO2 含受体位点；耦合位点方程因此可严格
消元为一个有界标量方程。新实现使用带区间保护的一维 Newton 迭代，通用多供体
体系仍走原定点算法，EOS 参数和物理方程均未改变。

| 工况 | 指标 | 优化前 | 优化后 | 改善 |
|---|---|---:|---:|---:|
| 0.05 day，1 rank | 循环耗时（s） | 80.966 | 4.178 | 19.38× |
| 0.05 day，1 rank | 非线性求解耗时（s） | 55.611 | 2.683 | 20.73× |
| 0.05 day，1 rank | 平均位点迭代/调用 | 431.61 | 4.47 | 降至 1/96.6 |
| 5 day，2 ranks | 循环耗时（s） | 1059.763 | 67.893 | 15.61× |
| 5 day，2 ranks | 非线性求解耗时（s） | 717.208 | 54.773 | 13.09× |
| 5 day，2 ranks | 平均位点迭代/调用 | 432.52 | 4.47 | 降至 1/96.8 |

完整优化后计算仍为 20 个接受步、0 个拒绝步、60 次 SNES 和 332 次 KSP；
最大组分质量相对误差为 `4.84e-14`。与优化前完整结果逐项比较，最终 2000 个
单元的主解最大列尺度相对差为 `1.31e-12`，相态状态最大列尺度相对差为
`6.85e-12`，属于求解路径改变引起的浮点舍入差异。优化结果保存在
`results/optimization/full_optimized`。

验证还包括 33 项完整单元测试、B2 压力自动微分与中心差分对照，以及保留原算法
的 water/methanol 多供体 CPA 回归，均通过。

### 6.1 通用多供体算法优化

随后又将多供体/多受体通用路径改为耦合位点 Newton 求解。程序直接构造最多
`2 × 组分数` 阶的供体–受体 Jacobian，使用带主元的稠密消元计算更新量，并通过
回溯线搜索保证所有未缔合位点分率满足 `0 < X <= 1` 且残差下降。如果矩阵退化或
线搜索失败，则自动回到原阻尼定点算法；因此该优化不缩小原算法的适用范围。

公开 ThermoPack water/methanol sCPA 参数的强交叉缔合液相状态
（389.375 K、0.233183 MPa、`x=[0.185,0.815]`）被加入持续性能基准：

| 指标 | 优化前阻尼定点 | 通用 Newton | 改善 |
|---|---:|---:|---:|
| 平均位点迭代/调用 | 118.04 | 5.00 | 降至 1/23.6 |
| 单相计算耗时 | 175.95 μs | 26.58 μs | 6.62× |
| 液相压缩因子 | 0.002920191895 | 0.002920191895 | 12 位小数一致 |

优化后耗时为连续 5 次、每次 2000 个相计算的中位数；优化前基线使用相同状态和
编译选项。微基准的绝对耗时会随系统负载波动，迭代次数和数值回归值是确定性的。

通用路径的压力自动微分已与中心差分分别对照压缩因子和水逸度系数。全部 33 项
单元测试再次通过；现有五组分 B2 流动算例使用独立单供体快速路径，复跑结果与
此前优化结果逐项完全相同（主解及相态 CSV 最大绝对差均为 0）。

## 7. 结论

1. 三套参数均完成 20 个公共物理时刻，0 个拒绝步、0 次井控重算，满足流动
   算例的稳定性和守恒验收条件。
2. PR 与 SW 的油气相分配和生产量接近；SW 主要改变水相密度、含盐水分配和
   少量气液性质，因此适合关注 CO2-brine 互溶时使用。
3. CPA 给出更高的油相饱和度、更低的气相饱和度和显著更低的生产井地面总流量，
   表明水-CO2 缔合处理会通过相态和密度继续影响井响应。
4. 优化前 CPA 的 Newton 次数并未增加，KSP 反而略少，但 wall time 是 PR 的约
   18.4 倍，证明瓶颈来自缔合热力学。单供体位点方程约化后，CPA 完整循环耗时
   降至 67.89 s，物理解保持不变；其成本已从位点定点迭代转移到密度根和其余
   热力学调用。
5. 因三种 EOS 使用各自适合的参数包，这是一项“工程模型包效果”比较，不应把
   差异全部解释为 EOS 代数形式的单因素效应。
