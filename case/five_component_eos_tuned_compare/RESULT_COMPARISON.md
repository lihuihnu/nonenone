# 五组分三状态方程流动结果图解

## 1. 比较目标

本报告比较 PR、SW 和 CPA 三套优选热力学参数包加入同一储层流动模型后的
物理响应与计算代价。三次计算使用相同网格、岩石、井、初始状态、边界条件和
时间表，仅热力学参数包不同。因此，图中差异代表“状态方程及其配套参数”的
整体效果，不是只改变状态方程代数形式的单因素实验，也不能单凭本算例判定哪套
模型更接近真实地层。

## 2. 计算条件与数据口径

| 项目 | 设置 |
|---|---|
| 流体 | H2O / CO2 / CH4 / C2H6 / nC4H10 |
| 网格与尺寸 | `20 × 20 × 5`；`1000 × 600 × 50 m` |
| 初始状态 | 60 bar，305 K，`z=[0.30,0.10,0.15,0.15,0.30]` |
| 注入井 | 纯 CO2，100000 reference m³/day |
| 生产井 | 52 bar 井底压力控制 |
| 模拟时间 | 5 day；20 个相同输出间隔 |
| 并行配置 | 2 MPI ranks |
| 数据集合 | 每种 EOS 21 个公共物理时刻，20 次收敛非线性求解 |

所有数据直接读取 `results/full/{pr,sw,cpa}`。生产井流量取模拟器负号约定的
相反数，以正值表示产出强度；注入井初始井底压力是未约束初猜，绘图时删除；
压力阴影是各网格单元的最小值至最大值范围，不是不确定度或误差带。

67.89 s，详见 `RUN_REPORT.md`。

## 4. 逐图解读

### 储层压力响应

![三种状态方程的储层压力响应](figures/zh/01_pressure_response.png)

三条平均压力曲线几乎重合，5 day 时 CPA 与 PR 的平均压力只相差
0.0196 bar。阴影范围随时间扩展，表示定产注入与定压生产在非均质储层内形成
空间压差；三套模型的整体压力传播相近。这里的平均压力接近，不代表局部压力场
完全相同。

### 末态相饱和度

![三种状态方程的末态相饱和度](figures/zh/02_final_phase_saturation.png)

PR 与 SW 的末态相分配很接近，SW 相对 PR 的油相仅增加 0.000983、气相减少
0.001596。CPA 相对 PR 的油相增加 0.124461、气相减少 0.121579，差异主要发生
在油气相之间，含水相只变化约 0.0029。该差异在初始闪蒸时已经存在，说明 CPA
的缔合与溶剂化处理先改变相平衡，再通过相对渗透率和流度传递到动态结果。

### 生产井地面产量

![三种状态方程的生产井地面产量](figures/zh/03_producer_surface_rate.png)

PR 与 SW 均从约 1.85 m³/s 平滑降至约 1.06 m³/s，5 day 的相对差仅 0.76%。
CPA 初始为 0.734 m³/s，在 0.25 day 达到 0.821 m³/s 后逐渐降至
0.642 m³/s；末态比 PR 低 39.88%。压力均值相近而产量明显不同，表明井响应
差异主要来自相态、密度与相流度组合，而不是整体储层压力不足。

### 含水相平均密度

![三种状态方程的含水相平均密度](figures/zh/04_water_phase_density.png)

三条曲线在 5 day 内都近似水平，说明当前注入体积尚未显著改变全域平均含水相
密度。SW 比 PR 高 0.16%，而 CPA 比 PR 高 18.53%。CPA 对含水相的高密度预测
与其显式水缔合和 CO2–水交叉缔合处理一致；这也是其体积换算和井流量与 PR/SW
明显分离的重要来源之一。

### 注入井井底压力

![三种状态方程的注入井井底压力](figures/zh/05_injector_bhp.png)

三组结果都在 0.75 day 左右达到峰值，此后缓慢下降。峰值分别为
63.557、63.573 和 64.331 bar；5 day 时 CPA 比 PR 高 0.423 bar。
在相同参考体积注入率下，CPA 需要更高的注入压力，反映其密度、相态和流度组合
对井源项换算及近井流动阻力产生了更强影响。

### 累计非线性求解时间（优化前基线）

![三种状态方程的累计非线性求解时间](figures/zh/06_cumulative_solver_time.png)

优化前 20 次非线性求解均收敛，但累计求解时间差异显著：CPA 是 PR 的 14.98 倍、
SW 的 18.27 倍。完整运行中三者 SNES 次数均为 60，CPA 的 KSP 次数甚至更少，
因此额外成本主要来自每次残差和 Jacobian 评估中的缔合热力学计算，而不是更差的
非线性收敛。该图据此用于展示优化目标；单供体位点方程约化后，同一 CPA 计算的
累计求解时间已降至 54.77 s。该图只累计求解器内部计时，故其比例与完整程序
wall time 比例不同。

## 5. 综合判断

1. **PR 与 SW 的动态流动结果高度接近。** 在本温压、组成和 5 day 尺度下，
   两者的压力、饱和度、井底压力和产量差异均较小；SW 的主要可见影响是含水相
   密度略高。
2. **CPA 给出不同的相态—物性—井响应链条。** 它预测更高油相分率、更低气相
   分率和更高含水相密度，并最终表现为更低产量与略高注入压力。
3. **CPA 的额外物理仍有计算成本，但已不再由低效位点迭代主导。** 本例中 CPA
   未造成收敛失败；优化后的完整循环为 67.89 s，与 PR/SW 已处于同一数量级。
   若继续优化，下一目标应是密度根及重复热力学调用，而不是放宽收敛容差。
4. **本比较不能替代实验标定。** 只有一个确定性地质模型、一个初始组成和一个
   温压条件，没有实验观测、重复样本或参数不确定性分析。当前结果适合比较三套
   模型加入流动后的行为与代价，不足以宣称某个 EOS 对真实储层“更正确”。

## 6. 图件与复现

- 仓库内保留正文直接引用的中文 PNG 预览：`figures/zh/`。
- 完整中英文 PNG/PDF 属于可再生成产物，不再全部纳入 Git；使用下述命令可按需重建。
- 绘图源数据：`figures/source_data.csv`
- 图件来源与变换记录：`figures/figure_manifest.json`
- 绘图程序：`plot_results.py`

复现命令：

```bash
python plot_results.py --force
```

图件统一为 160 mm × 100 mm、600 dpi；每张图仅含一个坐标窗，无网格，使用
颜色、线型和标记三重编码。中文版的坐标文字为中文，图例按要求保留英文。
