# 新 CPA 后端接入后的五组分算例重算与对比

## 1. 结论摘要

新 CPA 后端已进入生产热力学代码，并在同一可执行程序中完成 PR、SW、CPA 三组
`20 × 20 × 5`、5 day 算例重算。三组计算均为 20 个时间步接受、0 个时间步
拒绝，未发生井控重算或守恒诊断失败。

本算例采用 H2O 单供体、H2O/CO2 受体的 B2 缔合拓扑，因此实际走严格约化的
单供体快速路径；新接入的通用多供体 Newton 路径已经可用，但不会在不改变原始
物理参数的前提下被本算例触发。当前 CPA 物理解与上一版 B2 优化结果逐值完全
一致。相对最初定点算法，完整模拟耗时由 1059.76 s 降至 61.95 s，约为原来的
1/17.11。

## 3. 收敛、守恒与耗时

| EOS | 接受/拒绝步 | SNES | KSP | 求解器耗时（s） | 完整循环（s） | 最大组分质量相对误差 |
|---|---:|---:|---:|---:|---:|---:|
| PR | 20 / 0 | 60 | 363 | 45.62 | 54.42 | 1.19e-13 |
| SW | 20 / 0 | 60 | 363 | 45.31 | 55.06 | 1.14e-13 |
| CPA | 20 / 0 | 60 | 332 | 49.54 | 61.95 | 5.63e-14 |

CPA 的完整循环耗时为 PR 的 1.14 倍、SW 的 1.13 倍，已与两个非缔合模型处于
同一量级。CPA 的 SNES 次数与 PR/SW 相同、KSP 次数更少，说明当前额外成本来自
单次热力学计算，而不是更困难的非线性收敛。

三组结果的以下诊断文件均为 0 条记录：面通量失败、质量守恒失败、井源项失败、
井控切换。该结论覆盖全部时间步，而不只检查末态。

## 4. 物理解对比

| 5 day 指标 | PR | SW | CPA |
|---|---:|---:|---:|
| 平均储层压力（bar） | 59.9394 | 59.9396 | 59.9589 |
| 平均油相饱和度 | 0.592650 | 0.593633 | 0.717110 |
| 平均气相饱和度 | 0.334057 | 0.332461 | 0.212478 |
| 平均含水相饱和度 | 0.073293 | 0.073905 | 0.070411 |
| 含水相平均密度（kg/m³） | 845.414 | 846.788 | 1002.076 |
| 生产井地面产量（m³/s） | 1.06710 | 1.05897 | 0.64158 |
| 注入井井底压力（bar） | 63.2169 | 63.2283 | 63.6399 |

PR 与 SW 的压力、相饱和度和井响应接近。CPA 仍表现为更高油相饱和度、更低气相
饱和度、更高含水相密度、更低生产量和略高注入压力。重算后这些规律与历史结果
一致，因此 CPA 算法优化没有改变此前的工程解释。

### 储层压力

![储层压力响应](figures/recomputed_f405a18/zh/01_pressure_response.png)

三条平均压力曲线几乎重合；阴影仅表示 2000 个单元的最小—最大压力范围，不是
实验误差带。CPA 的局部压力范围略窄，但平均压力差不到 0.02 bar。

### 末态相饱和度

![末态相饱和度](figures/recomputed_f405a18/zh/02_final_phase_saturation.png)

PR 与 SW 的相分配接近；CPA 的差异主要发生在油气相之间，含水相平均饱和度差异
较小。这是热力学相分配再经相对渗透率和流度传递到流动结果的综合响应。

### 生产井地面产量

![生产井地面产量](figures/recomputed_f405a18/zh/03_producer_surface_rate.png)

PR 与 SW 基本重合。CPA 生产量明显较低，而平均储层压力与另两者接近，说明主要
原因是相态、密度和相流度组合，而不是储层整体能量不足。

### 含水相平均密度

![含水相平均密度](figures/recomputed_f405a18/zh/04_water_phase_density.png)

各 EOS 的全域平均值在 5 day 内变化很小。CPA 的显式水缔合及 CO2–水交叉缔合
使其含水相密度预测明显高于 PR/SW。

### 注入井井底压力

![注入井井底压力](figures/recomputed_f405a18/zh/05_injector_bhp.png)

CPA 在相同参考体积注入率下需要略高井底压力，反映近井相态、密度与流度组合的
差异。图中删除了未受井控约束的 `t=0` 初始猜测值。

## 5. 新旧算法的一致性

`compare_recomputed.py` 对以下六类 CSV 逐列比较：末态主解、末态相态、储层诊断、
井史、组分质量平衡和时间步历史。wall time 等非物理列被明确排除。

| 对比 | 结果 |
|---|---|
| PR 历史结果 → 当前结果 | 六类物理 CSV 最大绝对差均为 0 |
| SW 历史结果 → 当前结果 | 六类物理 CSV 最大绝对差均为 0 |
| B2 优化 CPA → 当前 CPA | 六类物理 CSV 最大绝对差均为 0 |
| 最初 CPA → 当前 CPA：末态压力相关量 | 最大绝对差 2.34e-7 Pa |
| 最初 CPA → 当前 CPA：末态相态量 | 最大绝对差 9.65e-9 |
| 最初 CPA → 当前 CPA：组分库存 | 最大绝对差 4.36e-4 kg |

最后一项应与约 `2.37e9 kg` 的总库存一起理解，属于改变迭代路径后的浮点舍入差异，
不构成可分辨的物理解变化。时间步序列、SNES/KSP 次数和井控状态完全一致。

## 6. 算法性能对比

![CPA 算法代际完整模拟耗时](figures/recomputed_f405a18/zh/07_cpa_algorithm_runtime.png)

| CPA 阶段 | 完整循环（s） | 相对最初版本 |
|---|---:|---:|
| 原始阻尼定点 | 1059.76 | 1.00× |
| B2 单供体约化 | 67.89 | 加速 15.61 倍 |
| 当前生产后端 | 61.95 | 加速 17.11 倍 |

当前后端与 B2 约化版本在本算例中执行同一条快速路径，所以 67.89 s 与 61.95 s
之间的差异只能视为两次运行的系统负载波动，不能归因于通用 Newton 算法。通用
多供体路径的独立 water/methanol 基准由 118.04 次降至 5.00 次位点迭代，单相
计算中位耗时由 175.95 μs 降至 26.58 μs；该验证见 `RUN_REPORT.md`。

![同批次三种 EOS 累计求解耗时](figures/recomputed_f405a18/zh/06_cumulative_solver_time.png)

同批次累计求解耗时避免了优化前后跨批次运行的负载混杂。CPA 为 49.54 s，PR 和
SW 分别为 45.62 s 与 45.31 s，显示缔合模型仍较慢，但已不是数量级差异。

## 8. 适用边界

本轮证明的是：新 CPA 后端接入后，既有 B2 五组分流动算例保持数值一致，并显著
降低原始位点定点迭代的成本。它不证明 CPA 一定比 PR/SW 更符合某个真实油藏，
也不能用本算例单独衡量通用多供体路径在流动耦合中的加速比。后者需要另建含两种
及以上供体组分、且参数来源明确的流动体系，作为独立实验，而不应篡改本算例参数。
